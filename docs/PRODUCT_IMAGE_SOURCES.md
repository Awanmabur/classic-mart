# Classic Mart seeded product-photo sources

The development reference catalogue may download real product photographs from Pexels when `npm run db:setup` or `npm run media:seed-stock` runs with internet access. Pexels marks these photo pages as free to use. The downloader only accepts HTTPS responses from `images.pexels.com`, validates JPEG content, limits file size, and writes atomically. If downloads are unavailable, the existing packaged artwork remains the offline fallback.

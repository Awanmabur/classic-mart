# Classic Mart Standalone Dashboard — Polished Final 17

This cumulative update starts from Polished Final 16 and targets the customer dashboard details requested after review.

## Corrected

- Support Centre topic cards are true rounded rectangles, matching the dashboard statistic-card visual language instead of capsule controls.
- Quick Actions are rounded rectangular stat-like cards rather than pill/circle containers.
- The dashboard workspace selector is larger on desktop and remains visibly usable on tablet/mobile instead of collapsing to a tiny icon-only control.
- The selector chevron is larger and sits inside the same clickable area as the native select.
- The invisible native select overlays the entire workspace selector, so clicking the label, dashboard icon, or arrow opens the dashboard list reliably.
- The visible workspace label synchronizes whenever the role changes.

- Curvy pill treatment for actual buttons and single-line form controls.
- Single-border input focus behavior.
- Four-column desktop Wishlist.
- Classic Mart orange primary theme.
- Role-aware Profile Settings pattern.

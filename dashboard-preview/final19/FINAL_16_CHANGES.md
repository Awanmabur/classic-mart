# Classic Mart Standalone Dashboard — Polished Final 16

This release is cumulative on top of Polished Final 15.

## Requested corrections

1. **Wishlist density** — the Wishlist page is four product cards across on desktop, three on medium screens, and two on phone layouts.
2. **Support Centre cards** — customer support topics now render as normal rounded dashboard statistic cards rather than capsule buttons.
3. **Dashboard selector** — the workspace selector is one coherent control with a dashboard icon, readable role labels, fixed chevron alignment, and a compact mobile interaction.
4. **Classic AI iconography** — a dedicated sparkles symbol replaces the generic star in the header, AI drawer brand mark, and AI assistant avatar.
5. **Profile Settings parity** — every non-customer role settings page now uses the same visual and interaction pattern as the customer Profile Settings page while keeping role-specific fields.

## Scope

The package remains a standalone HTML/CSS/JavaScript dashboard prototype. Forms and role flows are interactive demonstrations; no backend authority or persistence is implied.
